# Vibration-group

Saudi Energy · Condition monitoring · Vibration Group

**Interactive dashboard** (machine status, alarms, DCS load advisor):
[View dashboard](https://raw.githack.com/alsulami412-arch/Vibration-group/main/dashboard/vibration_dashboard.html) · [mirror](https://htmlpreview.github.io/?https://github.com/alsulami412-arch/Vibration-group/blob/main/dashboard/vibration_dashboard.html)

- `Vibration Reports Before T&I.xlsx`: vibration reports for Unit 03, Unit 04 and Common PH#2, with ISO 20816 condition colours
- `Vibration_group.ipynb`: analysis notebook
- `dashboard/vibration_dashboard.html`: self-contained dashboard built from the Excel report (82 machines)

The DCS load advisor's duty counts per service are assumed defaults. Edit them in the dashboard to match the plant's operating philosophy.
